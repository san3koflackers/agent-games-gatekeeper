# SanLav — Proof Gatekeeper agent

Cloudflare Worker competing in the **Proof Gatekeeper** track of
[zkVerify Agent Games](https://agentgames.zkverify.io) (Season 01).
Agent name: **SanLav**. Prizes: 100,000 VFY per track.

## What it does

For each task the platform POSTs to this Worker, the agent:

1. Verifies the `x-agent-games-signature` HMAC over the raw body bytes
   (HMAC-SHA256; secret from the `AGENT_GAMES_HMAC_SECRET` env var).
2. Answers the signed preflight (`{ ok: true, protocolVersion: "v1" }`) —
   required before the platform marks the agent active.
2. Answers duplicate `task_id` deliveries idempotently (same decision).
3. Runs the deterministic 7-way decision check (see below).
4. Records `proof_tx` in a KV seen-set (reuse detection across rounds).
5. Generates a local Groth16 proof of its decision with `snarkjs`
   (circuit: `GatekeeperEvaluation`, 13 public inputs, BN128) — skipped
   for `PROOF_REUSED` tasks, which carry no proof.
6. Returns `{decision, reason_code, proof_tx, proof, public_signals}`,
   HMAC-signed, inside the 60-second deadline.

Fail-closed policy: any uncertainty or error → `REJECT`. A decision
without a proof is still returned (correct decision without proof scores
+10; a timeout scores −2).

## Decision logic (7 trap varieties)

| reason_code | Decision | Condition |
|---|---|---|
| `VALID_CONDITION` | APPROVE | all checks pass |
| `VK_SUBSTITUTION` | REJECT | `proof_vk != registered_vk` |
| `THRESHOLD_MISMATCH` | REJECT | `public_balance < minimum` |
| `PROOF_REUSED` | REJECT | `proof_tx` already seen |
| `EXPIRED_CONDITION` | REJECT | `current_block > expiry_block` |
| `RECIPIENT_MISMATCH` | REJECT | `recipient != condition_recipient` |
| `AMOUNT_OVERFLOW` | REJECT | `amount > max_transfer` |

Boundaries: `balance == minimum` and `amount == max_transfer` are VALID;
`current_block == expiry_block` IS expired (proven by the circuit probe:
decision=1 fails the circuit at equality, decision=0 verifies).

## Layout

- `src/index.js` — Worker entry: health endpoint, HMAC gate, task flow.
- `src/decision.js` — pure decision engine (no I/O).
- `src/hmac.js` — HMAC-SHA256 sign/verify (WebCrypto).
- `src/prover.js` — snarkjs proving + circuit-input mapping.
- `src/wasm-b64.js`, `src/zkey-b64.js`, `src/vk.js` — embedded circuit
  artifacts (generated by `tools/build-assets.mjs` from `../circuits/`).
- `test/local-test.mjs` — local suite (`npm test`, dummy secret only).

## Secrets policy

**No secrets in this repo, ever.** The HMAC secret reaches production only
via `wrangler secret put AGENT_GAMES_HMAC_SECRET`. Never commit `.dev.vars`, never
paste the secret into code, docs, or logs.
